# Installable Python Project

This is a template for creating a Python project that can be installed with pip. To see how it works, first install it into a Python environment of your choice in editable mode. For instance, to install it using a venv do the following:

```sh
python3 -m venv venv
source venv/bin/activate
pip install -e .
```

This will install the project and its dependencies. Then try out the two scripts in the `examples` folder.
